Setup guide

🚀 One-time setup — about 5 minutes

The app runs on your Google Cloud $300 free trial. You only do this once.

Step 1 · Copy your Project ID

Open console.cloud.google.com. At the very top of the page, click the project name (next to the "Google Cloud" logo). A window pops up with a list — copy the value in the ID column (looks like banana-app-448212, letters and dashes, not just numbers).

Step 2 · Turn on the image API

Click here: enable the API and press the big blue Enable button. If it already says "API Enabled", skip ahead.

Step 3 · Install Google's sign-in tool

Download the Google Cloud CLI installer: cloud.google.com/sdk/docs/install. Run it and just click Next through everything (all defaults are fine).

Step 4 · Sign in — one time only

Press the Windows key, type cmd, press Enter. In the black window, paste this and press Enter:

gcloud auth application-default login

Your browser opens — sign in with the same Google account that has the free trial, and click Allow. When it says success, you can close the black window.

Step 5 · Connect this app

Open ⚙ Settings at the top of the app → paste your Project ID → Save → Test connection.

✅ Green message = you're done. Close this guide and start generating!

😵 If Test connection fails

  • "quota project" error → back in the black window, run gcloud auth application-default set-quota-project YOUR-PROJECT-ID (use your real ID)
  • 403 / permission error → redo Step 2, wait 2 minutes, test again
  • "gcloud not recognized" → finish Step 3, then open a new cmd window for Step 4

➕ Adding a second project (more quota)

Google limits how many images or clips one project can make per minute. A second project is a second, separate limit — MegaGen spreads every run across all the accounts you add, so hitting a limit on one no longer stalls the batch.

  • In the Cloud console create a new project, then enable the API on it (Step 2 again, for the new project).
  • ⚙ Settings → ＋ Add account → paste the new Project ID → Test.
  • No second sign-in is needed — your existing gcloud login already covers every project you own.
  • It doubles your speed, not your money. The $300 trial belongs to your billing account, not to a project, so a second project on the same account shares the same $300. That's why new accounts start with a credit of $0 — set it only if that project really bills separately.

🖼 The Images tab

  • Import .txt or Paste a numbered list — 1. text, 1) text, 1: text or 1 - text. Extra lines belong to the prompt above them.
  • You can also drag a .txt straight onto the left panel to import it, and Clear all wipes the prompt list or every reference in one click (with a confirm).
  • References bind to prompts by filename: 7.png is prompt 7's reference 1, 7-2.png is prompt 7's reference 2 (up to 6 per prompt).
  • Inside prompt 7's text, @1 and @2 mean that prompt's references. All of a prompt's references are sent whether or not the text tags them.
  • Outputs per prompt is 1–10. One press of Generate runs every prompt in number order.
  • Files land in output/<Project>/images as 7-gav482913.png.

🎬 The Videos tab

  • Drop start frames named by prompt number — 12.png is prompt 12's first frame. One frame per prompt.
  • Prompts without a frame are skipped (MegaGen never does text-to-video) and the panel says which.
  • Outputs per prompt is 1–3. Files land in output/<Project>/videos as 7Vid-gav482913.mp4.
  • Ratio must be 16:9 or 9:16.
  • Videos take 1–5 minutes each. The run card keeps counting while Google works — leave the app open and clips drop into the grid when ready.
  • Videos are billed per second, not per clip (estimates): Veo 3.1 $0.40 · 3.1 Fast $0.15 · 3.1 Lite $0.05 · Veo 3 $0.40 · 3 Fast $0.15 · Veo 2 $0.50 (no sound) · Omni Flash ≈ $0.10. An 8-second Veo 3.1 clip ≈ $3.20 — Veo 3.1 Lite is great for trying prompts cheaply (≈ $0.40 per 8s clip).
  • Omni Flash is brand-new (preview). If it errors with "isn't switched on for Vertex", Google hasn't enabled it for Vertex projects yet — use a Veo model until they do.
  • Omni Flash has no Seconds control — it always decides its own clip length (around 10s) instead of a fixed number you pick. Every other video model still lets you choose the exact length.
  • Seeing quota or rate limit errors? Videos have much tighter limits than images — the app already caps video jobs at 2 at a time; just wait a minute and try again.

⌨️ Cheatsheet — everything the mouse & keyboard can do

  • Ctrl+Enter anywhere = press Generate · runs stack, media appears live
  • Click a tile → fullscreen viewer: ←/→ browse, Del deletes, Esc closes, wheel zooms, double-click toggles 2.5×
  • Videos in the viewer: Space play/pause · M mute · F fullscreen · drag the bar to seek — ←/→ still switch between items
  • Ctrl+click toggles selection, Shift+click selects a range, drag a box on empty grid space to lasso, Ctrl+A selects all, Esc clears
  • Del deletes the selection (2 or more asks for confirmation first)
  • Ctrl+C with one image selected copies it to the clipboard
  • Hover any tile for quick actions: 🔄 regenerate · ✨ new · ✏️ edit · 📋 copy · 🗑 delete
  • ✏️ Edit a tile (or the pencil in fullscreen) = tweak that item's prompt and generate fresh takes right next to it — same model, settings and references; images let you pick 1–10 outputs.
  • Deleted things always land in output/.trash — recoverable, never destroyed
